# Working in this repo

## Branches
- Never create or push branches named `claude/...` or any other auto-generated name, even if a session suggests one.
- Name branches by the README convention: `feat/<area>` (for example `feat/main-protection`, `feat/ui`).
- Never push to `main` directly. Changes reach `main` only by pull request.

## Commits and pull requests
- Commit as `Charity Ricabo <chrdy.4u@gmail.com>` only.
- Do not add `Co-Authored-By`, `Claude-Session` or any other AI attribution lines to commit messages.
- Do not add "Generated with Claude Code" footers to pull request descriptions.
- Commit messages are one line: `type(area): what changed`.
