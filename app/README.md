# app/

The app and its API: turret view, pest photos, spray history, alerts, manual control, battery level and alerts, and a live view (planned). It runs on the Raspberry Pi 5.

The Increment 1 app (Next.js) is still at the repo root (`src/`, `scripts/`, `tests/`, `package.json`). It moves into this folder in its own pull request, after the open pull requests that touch `src/` are merged, so they do not conflict.
